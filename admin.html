GESTIÓN DEL TORNEO.

Edita resultados, eventos, fechas, plantillas y capitanes. Publicar cambios requiere acceso de colaborador en GitHub.

Importante: esta página no es un acceso privado. Cualquiera puede verla; solo los colaboradores autorizados en GitHub podrán publicar los archivos de datos. La opción «¿Quién soy?» no requiere contraseña ni verifica identidades. No introduzcas aquí contraseñas ni tokens. Tus cambios permanecen en este navegador hasta que descargues el archivo actualizado.

RESULTADOS Y ACTAS

Guarda goles del marcador aunque aún no conozcas a los jugadores. Para calcular premios individuales, después registra los eventos y porteros.

PLANTILLAS, FOTOS Y CAPITANES

Puedes subir la foto al crear cada jugador o cambiarla después. La imagen queda dentro del archivo data.js que exportarás para GitHub. Pide permiso a cada persona para publicar su fotografía.

NOMBRES Y COLORES

Puedes cambiar los nombres visibles, abreviaturas y colores. No cambies los identificadores técnicos: son los que vinculan equipos y partidos.

GUARDAR Y PUBLICAR

Descarga el archivo data.js y súbelo al repositorio, sustituyendo el anterior. Una vez confirmado el cambio en GitHub, la web pública se actualizará con el nuevo calendario, las tablas y los premios.

1. En GitHub, abre el repositorio del torneo.

2. Selecciona Add file → Upload files y sube el nuevo data.js para reemplazar el existente.

3. Pulsa Commit changes. GitHub Pages desplegará el sitio actualizado.

4. Avisad al otro administrador antes de editar la siguiente tanda de actas para evitar sobrescribir sus cambios.

Si vuestro repositorio está bajo una cuenta personal, añade dos usuarios como colaboradores desde Settings → Collaborators. Cada cual entrará con su propia cuenta GitHub.

IMPORTAR COPIA DE SEGURIDAD

Solo admite archivos JSON exportados por este editor. Carga la copia si necesitas recuperar datos que todavía no has publicado.
